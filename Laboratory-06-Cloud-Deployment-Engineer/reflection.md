# Mission 6 – Reflection

Before completing this mission, I believed that deploying an application involved numerous commands and manual setup procedures. However, after creating my `docker-compose.yml` file, I learned how **Infrastructure as Code (IaC)** makes deployment more efficient by allowing Nextcloud and MariaDB to be managed through a single, reusable configuration.

One of the important lessons I gained was the need for correct YAML indentation, since improper spacing can lead to configuration errors. I also used the `cat` command to review the contents of my configuration file and ensure that it was properly structured before deployment.

I also gained a better understanding of how environment variables allow Nextcloud to connect to MariaDB and make application settings easier to manage. This activity reminded me of the importance of protecting sensitive information, especially database credentials, which should never be exposed in public GitHub repositories.

Successfully deploying Nextcloud gave me practical experience in using Docker Compose to manage multiple containers efficiently. Watching the application run helped me appreciate how these tools are used in actual cloud computing and deployment environments.

Compared with Mission 1, my understanding of cloud computing has expanded significantly. I now recognize that cloud infrastructure involves more than online storage and virtual machines. It also requires proper configuration, networking, security, and resource management to create reliable and reproducible systems.

Overall, this mission strengthened my knowledge of Docker Compose, container networking, and application deployment. It also provided valuable experience that will help me understand and work with more advanced cloud technologies in the future.
