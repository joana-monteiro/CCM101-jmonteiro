# Checkpoint 2 - Explore the Three Cloud Platforms

## Google Cloud Platform (GCP) Research

### Brief Overview

**Google Cloud Platform (GCP)**, also referred to as **Google Cloud**, is a cloud computing platform developed by Google. It offers a wide range of services for **data storage, application hosting, database management, networking, artificial intelligence, and software development**.

Google Cloud allows businesses and developers to use computing resources through the internet without having to purchase, manage, and maintain their own physical servers and hardware.

### Global Infrastructure

Google Cloud operates a global infrastructure that is organized into **Regions** and **Zones**.

* **Regions** are geographic locations where Google Cloud operates its data centers and provides cloud services.
* **Zones** are separate locations within a region where cloud resources can be deployed and managed.
* Using resources across multiple zones can help improve the availability, reliability, and performance of applications.

This worldwide infrastructure allows organizations to deploy applications closer to their users, helping provide dependable services across different locations around the world.

### Cloud Management Console

The **Google Cloud Console** is a web-based interface used to access and manage Google Cloud services and resources.

Users can create **projects** to organize their cloud resources, services, settings, and access permissions. The console also includes tools for **monitoring** and managing cloud applications and infrastructure from one centralized platform.

### Four Core Services

| **GCP Service**                    | **Description**                                                                                          |
| ---------------------------------- | -------------------------------------------------------------------------------------------------------- |
| **Compute Engine**                 | Provides virtual machines that can be used to run applications, software, and other computing workloads. |
| **Cloud Storage**                  | Provides scalable cloud storage for files, images, videos, backups, documents, and other types of data.  |
| **Cloud SQL**                      | Provides a managed service for creating, storing, and maintaining relational databases.                  |
| **Google Kubernetes Engine (GKE)** | Allows developers to deploy, manage, and operate applications that run using containers.                 |

### Three Advantages

1. **Global Network** – Google's extensive worldwide network helps applications and users communicate efficiently across different geographic locations.

2. **Data and AI Capabilities** – Google Cloud offers powerful services for data processing, analytics, artificial intelligence, and machine learning, allowing organizations to work with large amounts of data and develop intelligent applications.

3. **Scalability** – Google Cloud resources can be increased or decreased based on the changing needs of an application or organization, allowing businesses to efficiently manage different workloads.

### Enterprise Use Case Scenarios

| **Scenario**                | **How GCP Can Be Used**                                                                                                               |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| **Website Hosting**         | Businesses can use Google Cloud infrastructure to host websites and web-based applications.                                           |
| **Data Storage**            | Organizations can use Cloud Storage to save documents, images, videos, backups, and other important information.                      |
| **Database Management**     | Companies can use Cloud SQL to store, organize, and manage relational business data.                                                  |
| **Data Analysis**           | Organizations can use Google Cloud services to process, analyze, and gain insights from large amounts of information.                 |
| **AI and Machine Learning** | Businesses can develop applications and solutions using artificial intelligence and machine learning technologies.                    |
| **Container Applications**  | Developers can use GKE to deploy, operate, and manage applications running in containers.                                             |
| **Application Development** | Developers can use Google Cloud services and tools to create, test, deploy, and maintain applications.                                |
| **Global Applications**     | Companies can deploy applications across multiple regions to improve accessibility, reliability, and performance for users worldwide. |

### Conclusion

**Google Cloud Platform (GCP)** provides a wide range of cloud services that help businesses and developers **create, deploy, store, and manage applications and data**. Its services support various needs, including website hosting, cloud storage, database management, data analytics, artificial intelligence, containerized applications, and software development.

With its **global infrastructure** and strong capabilities in **data analytics and artificial intelligence**, Google Cloud provides organizations with flexible and scalable solutions that can meet different computing and business requirements.
