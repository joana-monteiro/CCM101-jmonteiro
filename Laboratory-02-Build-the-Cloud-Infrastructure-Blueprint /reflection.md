# Cloud Infrastructure Laboratory Reflection

This laboratory activity helped me develop a better understanding of **cloud infrastructure** and how its different components work together. I learned that each part of a cloud environment has a specific purpose and contributes to the overall operation of cloud-based systems and services.

One of the key concepts I learned is the importance of **compute resources**. Compute provides the processing power needed to run applications, services, and workloads. However, compute resources cannot operate independently. They rely on **storage** to save and manage data and **networking** to allow users, applications, and systems to communicate with one another.

I also gained a better understanding of the role of **Linux in cloud computing**. Linux is widely used in cloud environments, particularly for servers and application hosting. During the laboratory activity, I used various Linux commands to examine the operating system, processor, memory, storage, and network configuration. This practical experience helped me understand how server resources can be viewed and monitored through the command line.

Another important lesson was the value of **technical documentation**. Proper documentation helps organize information and makes systems easier to understand, maintain, and troubleshoot. Creating a cloud architecture diagram and documenting the laboratory activities using Markdown allowed me to present my work in a clear and organized manner.

Overall, this laboratory improved my understanding of **cloud infrastructure, Linux, networking, computing resources, storage, and technical documentation**. It also gave me practical experience that will be useful in future cloud computing activities and projects.
