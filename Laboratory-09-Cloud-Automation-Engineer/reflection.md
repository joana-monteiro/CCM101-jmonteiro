## Importance and Risks of Automation

Automation plays an important role in managing hundreds or thousands of cloud servers because manually performing repetitive tasks requires significant time and may lead to human errors. Through scripts and scheduled tasks, system administrators can execute routine operations more efficiently and consistently. However, automation also involves risks. An incorrect command or poorly configured script could cause problems across multiple servers if executed without proper validation. Therefore, testing scripts, reviewing configurations, and preparing recovery procedures are essential practices.

## Bash Scripting vs. Docker Compose YAML

Creating a Bash script was different from working with a Docker Compose YAML file during Mission 6. Bash scripting involves executing commands, defining variables, and automating a series of tasks. In contrast, Docker Compose YAML is used to define application services, container settings, and their relationships. Although both technologies help simplify technical processes, they have different functions and applications.
